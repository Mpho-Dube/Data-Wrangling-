# Data-Wrangling-
Data Wrangling and Transformation Project
# WWD 182 SS2 — Data Wrangling and Transformation

## Project Overview
This project forms the second stage of a structured case study
developed across the WWD 182 Working with Data module Information Technology\Data Science.

## Dataset
- Primary dataset: Bank Churn Modelling
- Source: https://raw.githubusercontent.com/YBI-Foundation/Dataset
  /main/Bank%20Churn%20Modelling.csv
- Additional dataset: Bank_Churn_Modelling_extra_UPDATED_v2.csv

## Assignment Structure
| Part | Description | File |
|---|---|---|
| Part 1 | Data wrangling, consolidation, and structural refinement | .ipynb |
| Part 2 | Segmentation, aggregation, and pivot-based structuring | .ipynb |


## Skills Demonstrated
- Data loading and structural evaluation
- Dataset consolidation using pd.concat()
- Duplicate detection and resolution
- Missing value treatment using median and mode imputation
- Data type management and structural refinement
- Customer segmentation using pd.cut() and pd.qcut()
- Grouped aggregation using groupby()
- Pivot table construction using pivot_table()
